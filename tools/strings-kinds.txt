# Which kind of control a text lives in, for the length check of tools/strings-check.ps1.
#
# A key can name its own kind in its note (the part "| kind: chip" of the comment above it); that wins.
# Otherwise the first line of [kinds] whose glob matches the key decides, and a key that matches none is
# a "body" text: no limit. Rooms in English characters (docs/design-language.md, 13.2):
#   tab 10, button 22, chip 18, title 28, row 40, pet 80, widget 14.
# A placeholder counts as 2 characters. English must fit the room; a translation must fit
# floor(room * 1.4), the size of the stretched test language.
#
# Format: one "<kind> <glob>" per line; a glob may use * and ?; "#" starts a comment.
