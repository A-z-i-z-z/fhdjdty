# Wave 0 performance numbers (layout; the lead fills in the numbers)

Tools: `tools/phone-perf.ps1` writes `dist\perf\<label>\<scenario>.json`, `summary.json` and `memory.json`. Tables below come from
`powershell -NoProfile -ExecutionPolicy Bypass -File tools\phone-perf.ps1 -Report dirA,dirB -Markdown <file>`.
Budgets are the ones of `docs/design-language.md` section 11. They apply to the optimised build; a debug build is several times slower.

This file names the phone model and the Android version only. It never carries a serial number, an adb serial, an account or any chat text
(the repository is public).

## 7. How to reproduce

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\phone-perf.ps1 -Owner -Scenario P1,P6,P7 -Label before-build32
powershell -NoProfile -ExecutionPolicy Bypass -File tools\phone-perf.ps1 -Owner -Scenario P1,P4,P5,P6,P7 -Label owner-debug-after
powershell -NoProfile -ExecutionPolicy Bypass -File tools\phone-perf.ps1 -Mode Memory -LimitMb <room>
powershell -NoProfile -ExecutionPolicy Bypass -File tools\phone-perf.ps1 -Report before-build32,owner-debug-after -Markdown dist\perf\compare.md
```

`-AllowSystemSettings` (animation scales 1, font scale 1.0, restored afterwards) is passed by the lead only; without it the owner's own
scales stay and a note says so.
