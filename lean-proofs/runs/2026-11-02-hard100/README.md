# 100-agent run on the harder queue, 2026-11-02

- Queue: `queue/hard100.jsonl` (generated by `queue/make_hard100.py`), 100 Mathlib statements in three tiers:
  exercise (25, textbook), stretch (39, multi-step), olympiad (36, competition style: IMO 1959 P1, IMO 1995 P2,
  IMO 1984 P1 upper half, n | 2^n - 1 ⇒ n = 1, ⌊√n + √(n+1)⌋ = ⌊√(4n+2)⌋, cos 36° - cos 72° = 1/2, ...).
- 1 Haiku 5.5 agent per lemma (`claude -p`, all tools off), up to 4 rounds with Lean feedback.
- Lean 4.35.0 + Mathlib v4.35.0, cloud container, 4 CPUs, `--concurrency 10 --verify-workers 3 --library-check`.

| Tier | Proved | First try | Calls | Cost (USD) | `exact?` found it in library |
|---|---|---|---|---|---|
| exercise | 25/25 | 25 | 25 | 0.029 | 8 |
| stretch | 38/39 | 36 | 44 | 0.084 | 5 |
| olympiad | 36/36 | 30 | 42 | 0.110 | 2 |
| **total** | **99/100** | **91** | **111** | **0.223** | **15** |

- The only failure: `s_pow_mod_1000` (`2 ^ 2026 % 1000 = 864`). All 4 attempts left the goal unsolved;
  `native_decide` is banned and the agent didn't find a `decide`/`norm_num` route that evaluates it.
- All 99 proofs were re-compiled independently with `lake env lean`: 0 errors, each main statement matches the
  queue text exactly, no banned tokens, axioms only from {propext, Classical.choice, Quot.sound}.
- 85 of the 99 proved statements were not closed by a single `exact?` call. That does not prove they are new to
  Mathlib, only that no one library lemma states them directly. They are competition exercises, not Mathlib material.

Takeaway: one Haiku agent with 4 rounds clears even olympiad-style statements at this size. To find where it
breaks, the next queue needs research-level or long multi-lemma targets (e.g. formal-conjectures, miniF2F/PutnamBench-hard).
